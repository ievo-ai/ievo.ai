iEvo

AI agents that learn from mistakes.
A self-evolving development team in your terminal.

Three pillars

Not another orchestrator. A methodology layer that makes AI agents disciplined, testable, and self-improving.

⚙

Spec-Driven Development

Every feature starts as a formal spec. Atomic requirements with testable acceptance criteria. No vague instructions, no hallucinated scope. Specs drive everything — plans, code, tests, reviews.

⚖

Agent Marketplace

Install agents like packages: ievo add spec-writer. Each agent brings its own role, memory, skills, and MCP integrations. Dependencies auto-resolve. Domain experts plug in when needed.

✶

Self-Evolution

Every agent has an EVO skill. Mistakes trigger root-cause analysis, ROLE.md updates, and evolution logs. A Curator agent aggregates lessons across all projects — genetic algorithm improves agents collectively.

Self-evolution

Agents learn from every mistake. A genetic algorithm ensures only improvements survive.

Error Detected

Agent makes a mistake. User says /evo or the on_error hook fires automatically.

Root Cause Analysis

EVO skill classifies the error, identifies the wrong assumption, and formulates an actionable rule.

Mutate ROLE.md

A new rule is proposed. After user approval, ROLE.md is updated and the change is logged.

Collective Learning

Evolution logs from all projects flow to the Curator. Patterns emerge. The marketplace agent evolves.
